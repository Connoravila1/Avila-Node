# Bitcoin 0.1 interface assets

Copyright (c) 2009 Satoshi Nakamoto. MIT/X11; see LICENSE.txt.

`send20.png` and `addressbook20.png` are lossless RGBA conversions of the
original 20 x 20 BMP files, with alpha taken from their monochrome mask
files. `bitcoin16.png` and `bitcoin48.png` are the original ICO frames. These are
original assets, not generated replacements. All are rendered with
nearest-neighbor filtering to preserve the source pixels.

`client-preview.png` is a reduced screenshot of Avila's rendered OG skin,
used for its Toybox card. The data in the thumbnail is simulated.
