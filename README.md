# Avila Node

A personal, MIT-licensed Bitcoin full-node project by Connor Avila, written in Rust with an egui desktop interface.

The goal is a complete, independently usable node that someone could choose as their primary node, while exploring better implementations of validation, storage, networking, privacy, policy, and usability. Experimental describes development maturity and novel engineering, not a reduced definition of a working node.

Project scaffolding and the implementation roadmap are being established. This initial commit does not yet implement a Bitcoin node.
