# Avila Node

An open-source Bitcoin full node in Rust, with a native egui desktop, by Connor Avila.

The aim is a node anyone could run as their primary node, and the best one they could
choose: independently validated, fast, frugal, private, resilient, and understandable.
Bitcoin Core compatibility and lightweight operation are the floor, not the ceiling.
Claims are earned through published, reproducible evidence, never asserted ahead of it.

The full ambition is laid out in the [scope](docs/SCOPE.md) and [roadmap](ROADMAP.md).
The [scorecard](docs/SCORECARD.md) defines how results will be judged.

## Status

Early development. See the roadmap for what exists, what is next, and the acceptance
evidence each stage requires. Development notes are in [CONTRIBUTING.md](CONTRIBUTING.md).
