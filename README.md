# Avila Node

An open-source Bitcoin full node in Rust, with a native egui desktop.

The aim is a node anyone could run as their primary node, and to experiment a bunch of different ideas. This is a side project of mine that I update when I have time. Don't take it too seriously. I'm mostly curious to see how far I can push this project's capabilities. If anything works really well, this is licensed for anyone to take anything they want. Go nuts. 

The full ambition is laid out in the [scope](docs/SCOPE.md) and [roadmap](ROADMAP.md).
